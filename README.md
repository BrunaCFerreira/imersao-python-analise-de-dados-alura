## ▶️ Como executar

Abra a pasta raiz do repositório no VS Code/Jupyter ou Colab. Instale as dependências com `pip install -r requirements.txt`. Execute os notebooks na ordem das células. O primeiro notebook usa o caminho relativo `content/Atividade prática Alura.xlsx`, considerando que a pasta de trabalho atual seja a **raiz do repositório**. No Colab, faça upload da pasta `content` ou ajuste o caminho.

Os notebooks 2 e 3 baixam dados do Yahoo Finance e precisam de internet; versões das bibliotecas e alterações na fonte podem mudar os resultados. A previsão com Prophet é um exercício didático, não uma recomendação financeira.
